# 东南大学目录与课程数据口径

学院、专业和课程示例只用于界面选项及本地验收数据，不代表真实在校人员或当前开课结果。

## 学院与专业

- 学院名称以东南大学官网“院系部门”和本科专业公开信息为依据。
- 学院与专业在客户端使用联动选择，不允许将专业保存到不匹配的学院。
- 计算机科学与工程学院对应“计算机科学与技术”，软件学院对应“软件工程”。

官网来源：

- https://www.seu.edu.cn/17399/list.htm
- https://xxgk.seu.edu.cn/2024/1105/c10878a509242/page.htm

## 计算机科学与技术课程

班级年份由 common 的 StudentCohortYears 统一提供，录入新生和档案维护自动填写并锁定，服务端校验一致性。建筑学按五年制，例如建筑学2026级2班为2026—2031；城乡规划、风景园林2026级按四年制，历史2024级沿用五年制。其他模拟本科班级沿用当前四年制默认规则，非目录历史班名保留原字段；不能据此推断所有医学、研究生或特殊培养项目的真实学制。

建筑学及相关专业来源：

- https://arch.seu.edu.cn/2026/0623/c9118a572905/page.htm
- https://zsb.seu.edu.cn/2023/1207/c23655a474145/page.htm

课程代码、课程名称和学分来自用户提供的《09-2024级计算机科学与技术本科专业培养方案-印刷版提交.pdf》。示例包括程序设计基础及语言、离散数学、数据结构、计算机组成原理、操作系统、算法设计与分析、计算机网络、数据库原理和软件工程等。
