# 图片与商品评价

## 用户入口

| 图片 | 操作人员 | 入口 | 保存时机 |
| --- | --- | --- | --- |
| 个人头像 | 当前账号本人 | 个人中心 → 上传头像 | 沿用个人资料保存流程 |
| 商品图片 | 商店管理员 | 校园商店 → 商品管理 → 选择商品/新建商品 → 选择商品图片 | 点击保存商品；支持更换、移除 |
| 图书封面 | 图书管理员 | 图书维护 → 选择图书/新建 → 选择封面图片 | 点击保存图书；支持更换、移除 |
| 充值二维码 | 部署人员 | 项目运行目录 `config/recharge-qr.png` | 替换配置图片；学生只查看，不提供修改收款码入口 |

图片入口直接选择本机 JPG/PNG，不要求填写文件路径或 URL。上传前检查文件实际格式、大小和像素，保持比例生成预览；头像使用居中裁剪。源文件上限 5 MiB、1200 万像素；压缩结果上限 256 KiB。商品图按 640×480、图书封面按 210×280、头像按 256×256 处理。

商品图片通过服务端保存在 MySQL，而不是只保存在上传者电脑。其他客户端连接同一服务端即可读取；商品列表携带图片引用，图片按需独立加载。替换会产生新引用，避免旧缓存继续显示；未更换图片的普通商品编辑会保留原图。学生不能上传商品图片，也不能通过图片接口读取非在售商品的图片。历史 HTTP/HTTPS 商品图继续兼容。

头像沿用 `users.avatar_url` 中的数据内容保存方式；图书封面沿用 `books.cover_image`。充值仍是项目约定的扫码图片与人工确认演示流程，不代表已接通第三方支付回调。

## 商品详情与评价

- 选购商品中选择一行点击“查看商品详情”，或者双击商品。
- 详情包含图片、说明、价格、库存、评分与公开评价；无需先购买就可以查看评价。点击评价行查看全文；支持内容搜索和分页。
- 学生可直接从详情加入购物车，成功后刷新购物车。
- “商品评价”标签用于写评价：按订单号/商品名查询本人的待评价商品，选择后填写评分和内容，无需输入数据库编号。
- 候选由服务端分页，不再截断为前 100 笔订单；只显示已完成且尚未评价的订单商品。提交期间禁用重复提交，成功后候选移除。权限、订单归属和一次评价规则仍由服务端校验。
- 公开列表与评分使用可见页面刷新机制；多端同步仍依赖连接同一服务端。

## 升级

已有 V19 数据库在项目根目录启动 MySQL 客户端后，执行：

```sql
source vcampus-server/src/main/resources/db/migration/V20__store_product_images.sql;
```

V20 仅幂等新增 `products.image_data MEDIUMBLOB`，不重置数据。`image_url` 保留历史地址或 `store-image:` 引用。升级时同时替换服务端和 Swing 客户端程序。

```powershell
.\mvnw.cmd -pl vcampus-client,vcampus-server -am -Pquality verify
```

本次不修改或构建 JavaFX 实验模块。具体测试证据见 [验收报告](END_TO_END_REVIEW_2026-09-12.md)。
