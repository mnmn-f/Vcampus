# 绿色图书馆 UI 修改说明

本次修改将学生端图书馆重新设计为统一的绿色主题工作区，保留已有服务接口与业务数据。

## 页面调整

- 首页：增加问候与全局图书搜索、当前借阅/即将到期/今日预约概览、真实馆藏推荐、图书馆公告和近期预约。
- 图书查阅：改为图书卡片布局；每本图书直接显示封面、作者、分类、位置和可借数量；借阅按钮与图书 ID 绑定；右侧显示待归还图书并提供对应的归还按钮。
- 自习室预约：采用日期、开始时间、结束时间和楼层筛选；选择房间后在右侧确认；页面下方显示“我的预约记录”并可取消。房间搜索会排除所选时段已被预约的房间。
- 线上资源：取消嵌套页签，统一为“PDF 资源、网站资源、我的上传、下载记录”单层导航；PDF 支持逐项或批量选择下载；网站资源不再常驻显示原始 URL 或技术字段。

## 视觉调整

- 沿用项目原有东大绿主题色，统一浅绿选中状态、白色卡片、浅灰绿色页面背景和细边框。
- 图书馆内部使用固定左侧导航和顶部路径栏，功能切换时内容区独立滚动。
- 真实封面存在时显示真实封面；缺少封面时根据书名生成绿色系占位封面。
- 增加 Microsoft YaHei、Noto Sans CJK SC、思源黑体等中文字体回退。
- 学生页面移除“资源详情：类型、地址、说明”等技术信息条，以及连接、数据库、协议等内部提示。

## 主要文件

- `LibraryUi.java`：图书馆专用卡片、按钮、状态标签、封面和响应式布局。
- `LibraryTaskTabs.java`：固定侧栏、路径栏和独立页面滚动。
- `LibraryHomePanel.java`：学生首页。
- `LibraryCatalogPanel.java`：馆藏、借阅和归还。
- `LibraryRoomBookingPanel.java`：房间预约与预约记录。
- `StudentLibraryOnlinePanel.java`：PDF、网站、上传和下载入口。
- `RealLibraryPage.java`：学生端四个页面的组合入口。

## 验证结果

- Java 17 对客户端和服务端全部主源码编译通过。
- 学生端四个页面完成 1360×900 无显示器实际渲染。
- 自动交互冒烟验证通过：借阅记录由 2 条增加至 3 条；预约记录由 1 条增加至 2 条。
- Maven 仓库在本次运行环境中暂时无法解析，因此最终 JAR 使用 Java 17 编译器和项目现有依赖重新组装；项目源码可在网络恢复后继续使用 Maven Wrapper 构建。
