# 编码与质量约束

## Java格式

- UTF-8，4个空格缩进，不使用制表符。
- 包名全小写；类和接口使用 PascalCase；方法和变量使用 camelCase；常量使用 UPPER_SNAKE_CASE。
- 一个源文件只定义一个顶级类；每个公共类和边界接口写明职责。
- 文件原则上不超过200行。超过时先检查是否混合了多个职责。
- 不使用通配符导入，不提交未使用代码、注释掉的旧实现和重复工具类。

## 分层

- View 只处理展示与收集输入。
- Controller 处理页面状态和调用编排。
- Client Service 只通过消息网关请求服务端。
- Server Service 执行业务规则、权限和事务。
- DAO 只执行持久化。
- DTO 不包含数据库连接、Swing组件或业务服务。

## 错误处理

- 可预期业务失败使用稳定的结果码和用户可理解的文案。
- 不向客户端返回堆栈信息、SQL或内部类名。
- 不捕获后忽略异常；边界层负责记录技术细节并转换结果。
- 客户端字段错误就近显示，页面错误显示在内容顶部。

## 去冗余审查

提交前检查：是否已有公共组件；是否重复实现权限、分页、时间冲突、状态标签或表格工具栏；接口是否真的隔离网络/持久化/外部服务；数据库字段是否属于该实体；是否可以删除而不损失行为。
